# #2421 - Renzo ezETH liquid restaking integration

- PR: https://github.com/KeeperHub/keeperhub/pull/2421
- Issue: #2392
- State: **open, CI green** (pending maintainer re-review)
- Area: protocol registry

## What it does

Adds Renzo ezETH restaking. The RestakeManager pause gate output is named so its advertised
template path is the one `structureAbiOutputs` produces, which means a workflow can read
`paused` at runtime instead of getting a bare value it cannot bind to.

## Review items resolved

- pause gate readable at runtime (output named) -> fixed.
- write simulations require non-null revert data, so a test proves the deployed bytecode parsed the calldata rather than passing on any CALL_EXCEPTION.
- the discriminator was hardened to reject empty shapes on whichever RPC answers, after one public RPC reported unknown selectors as null and another as 0x.
- mainnet-scoped; addresses verified on-chain.
