# #2422 - Coinbase cbETH read integration

- PR: https://github.com/KeeperHub/keeperhub/pull/2422
- Issue: #2394
- State: **merged**
- Area: protocol registry

## What it does

Adds Coinbase cbETH as a read integration in the protocol registry, so agents and workflows
can read its exchange rate and supply without hand-writing an ABI call.

## Proof through KeeperHub (live mainnet read)

```
$ kh read 0xBe9895146f7AF43049ca1c1AE358B0541Ea49704 "exchangeRate()" --chain 1 --rpc-url https://ethereum-rpc.publicnode.com
1139686501937561335        # 1.13968 ETH per cbETH
$ kh read 0xBe9895146f7AF43049ca1c1AE358B0541Ea49704 "totalSupply()" --chain 1 --rpc-url https://ethereum-rpc.publicnode.com
393750601365061869784889
```
