# #2423 - ether.fi weETH/eETH liquid restaking integration

- PR: https://github.com/KeeperHub/keeperhub/pull/2423
- Issue: #2391
- State: **open, CI green** (pending maintainer re-review)
- Area: protocol registry

## What it does

Adds ether.fi weETH and eETH, and the `approve-eeth` action so the stake-then-wrap path is
completable in product (matching how Lido exposes `approve-steth`). Addresses were verified
on mainnet: `weETH.eETH()` returns the declared eETH address, and getRate / amountForShare /
getEETHByWeETH are byte-identical, real proof the addresses belong together.

## Review items resolved

- missing approve action -> `approve-eeth` added and exposed.
- vacuous write tests -> now require non-null revert data.
