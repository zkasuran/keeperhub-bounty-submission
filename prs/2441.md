# #2441 - Sky/USDS L2 contract split

- PR: https://github.com/KeeperHub/keeperhub/pull/2441
- State: **open, CI green** (pending maintainer re-review)
- Area: protocol registry

## What it does

Splits Sky/USDS (and Lido wstETH) into a mainnet contract with the full ABI and a read-only
L2 contract for chains where the deployment only implements the ERC-20 surface. This stops L2
chains from advertising ERC-4626 vault functions their deployments revert on. The dead
`get-susds-total-assets-l2` action was removed and the goldens regenerated.

## The fix, shown live through KeeperHub

`totalAssets()` is an ERC-4626 method present only on the mainnet vault. On Base and Arbitrum
the deployed sUSDS is a bridged token, not a vault, so the call reverts, while `balanceOf`
still works. That contrast is the whole reason for the split.

```
$ kh read 0xa3931d71877C0E7a3148CB7Eb4463524FEc27fbD "totalAssets()" --chain 1     --rpc-url https://ethereum-rpc.publicnode.com
4381515516014605268821377264      # mainnet: answers
$ kh read 0x5875eEE11Cf8398102FdAd704C9E96607675467a "totalAssets()" --chain 8453  --rpc-url https://base-rpc.publicnode.com
X RPC error 3: execution reverted # Base: reverts
$ kh read 0xdDb46999F8891663a8F2828d25298f70416d7610 "totalAssets()" --chain 42161 --rpc-url https://arbitrum-one-rpc.publicnode.com
X RPC error 3: execution reverted # Arbitrum: reverts
$ kh read 0x5875eEE11Cf8398102FdAd704C9E96607675467a "balanceOf(address)" 0x33a4...8ff4 --chain 8453 --rpc-url https://base-rpc.publicnode.com
0                                 # Base: balanceOf works (the read the PR keeps)
```
