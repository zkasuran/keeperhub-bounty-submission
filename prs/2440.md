# #2440 - ABI-derived output field paths

- PR: https://github.com/KeeperHub/keeperhub/pull/2440
- Issue: #2424
- State: **open, CI green** (pending maintainer re-review)
- Area: workflow editor / protocol registry

## What it does

Protocol read actions advertised output field paths that did not exist in the runtime result
shape, so a template like `{{Node.balance}}` resolved to undefined with no error. This PR
makes advertised paths match what `structureAbiOutputs` actually returns at runtime.

## History (stated plainly)

Opened against #2424 on 2026-09-14. A sibling PR (#2535, issue #2514) later merged an
equivalent ABI-derived fix on staging on 2026-09-18. Rather than ship a duplicate
implementation, this PR was rebased onto staging as a **test-only** PR: a registry-wide guard
asserting every curated label lands on the exact runtime path, pinning 400+ label placements.
It is proven to bite: reverting staging's positional join fails 4 of 7 cases with 507
mislabeled fields. `lib/protocol-registry.ts` on this branch is byte-identical to staging.
